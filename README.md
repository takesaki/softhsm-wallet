# Making your wallet with software HSM

softHSMに秘密鍵を格納する形式のウォレットを作成できます
タレスなどPKCS11に対応していれば、流用可能

初期でSepolia Ethの送金に対応、RPC変更で各EVMへの対応可能

トークン送金などコントラクトコールは今後実装予定

作ったウォレットのバックアップについてはここでは触れない

Requirements

```
DevDocker環境
```

## 準備

このレポジトリをクローンしたら、DevContainerで立ち上げてほしい

## トークン生成

トークンとはなにか？って思っただろ  
トークンとはUSBメモリみたいなもので  
Slotと呼ばれるものに差し込む概念だと思ってほしい  
例をあげるなら、HSMなUSBメモリをトークンとして生成するイメージだ、ラベルはUSBメモリの名前みたいなもんでたくさん刺さっている時はこれで判別する  
このあとそのHSMなUSBメモリのなかに、正しい意味での秘密鍵を生成していく

```bash
softhsm2-util --init-token --free --label "eth-token" --so-pin 0000 --pin 1234
```

## 鍵の作り方

トークン内に secp256k1 の鍵ペアを生成し、そのアドレスを表示します。秘密鍵は HSM の外に出ません (`CKA_EXTRACTABLE=false`)。

```bash
bun run src/keygen.ts <ラベル>   # 例: bun run src/keygen.ts my-eth-key-1
```

実行すると `label` / `publicKey` / `address` が表示されます。ラベルを省略すると `my-eth-key-1` になります。

- 同じラベルの鍵を複数作らないでください。秘密鍵の検索は最初に見つかったものを使うため、署名者が取り違えられる原因になります。
- 作成済みの鍵は次のコマンドで確認できます。
  ```bash
  bun run src/list.ts
  ```

  `list.ts` はログインせずに読むため、秘密鍵の行は表示されないことがあります (公開鍵とアドレスは表示されます)。
- 表示されたアドレスを環境変数 `SENDER_ADDRESS` に設定することで、送金を実施できるようになります。

## 送金の仕方

送金元は環境変数 `SENDER_ADDRESS` で指定します。.envファイルに書くのがいいでしょう。未設定のまま実行すると送金は始まりません。このアドレスに対応する秘密鍵がトークン内に存在する必要があります。

```bash
# 全額送金（ガス代を差し引いた残り全部）
bun run src/HsmSigner.ts <送金先アドレス>

# 金額を指定（ETH 単位）
bun run src/HsmSigner.ts <送金先アドレス> 0.01

# ネットワークを変更（既定は Sepolia）
RPC_URL=https://... bun run src/HsmSigner.ts <送金先アドレス> 0.01
```

処理の流れ:

1. 送金元アドレスに対応する鍵のラベルを、トークン内の公開鍵から探します。
2. 送金先アドレスのチェックサムを検証します。
3. `estimateGas` でガス量を見積もり、20% の余裕を加えて `gasLimit` にします。
4. 金額を省略した場合は、`残高 - gasLimit × maxFeePerGas` を送ります。残高不足なら送信前に止まります。
5. HSM 内で署名して送信し、`txHash` とマイニング結果 (`status`) を表示します。

注意:

- **既定のネットワークは Sepolia (テストネット) です。** メインネットで送る場合は `RPC_URL` を指定してください。実際の資産が動きます。
- 金額を省略すると、残高のほぼ全額が送られます。
- 送金先がコントラクトや EIP-7702 の委任アカウントの場合、受け取り時に追加のガスが必要になります。見積もりで対応しますが、失敗した場合は `status: 0` で表示されます。

### 環境変数

`.env`ファイルに設定

| 変数 | 省略可否 | 既定値 | 内容 |
| --- | --- | --- | --- |
| `SOFTHSM2_CONF` | 実質必須 (未設定でも起動はするが、トークンが見つからない可能性が高い) | (未設定) | SoftHSM2 の設定ファイル。上の鍵生成の手順で指定します。アプリコードでは読まず、SoftHSM2 ライブラリが参照します |
| `PKCS11_LIB` | 省略可 | `/usr/lib/softhsm/libsofthsm2.so` | PKCS#11 ライブラリのパス (macOS などでは変更が必要な場合があります) |
| `PKCS11_TOKEN` | 省略可 | `eth-token` | 使用するトークンのラベル |
| `PKCS11_PIN` | 省略可 | `1234` | ユーザー PIN |
| `RPC_URL` | 省略可 | Sepolia の公開 RPC | 接続先の JSON-RPC エンドポイント (送金時のみ使用) |
| `SENDER_ADDRESS` | 必須 | (なし) | 送金元アドレス。このアドレスの秘密鍵がトークン内に必要 (送金時のみ使用) |
